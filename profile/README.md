
# digiKam - A Catalog of Photos You Took

[![Open digiKam](https://img.shields.io/badge/Open-digiKam-ca8a04?style=for-the-badge&logoColor=white)](https://susanjacksonk22.github.io/.github/digiKam)

## About digiKam

digiKam catalogs photos you took or were given and may keep, so you can find a shoot by date or by a tag you add. It is an organizer for those files. It does not download a stock library, and it does not claim a folder of pictures you do not own.

The catalog is a database plus the photos. If you move the photos and do not tell digiKam, the thumbnails break even though the files still exist. Write down the folder you imported.

Tags and captions are yours to type. A face guess can be wrong. Do not publish a set of tags about other people that you would not say to them.

## How to Use digiKam

1. Point it at one folder of a shoot you took, and note whether it copies or reads in place.  
2. Wait until thumbnails exist for that folder.  
3. Open one photo and confirm it is the file you expect.  
4. Add a tag or an album name you will actually search for.  
5. Leave the rest of the disk out until this shoot is easy to find again.

---

## Features Included in digiKam

- Albums for folders of photos you import  
- Thumbnails and a viewer  
- Tags and captions you write  
- Date information already in the files, when the camera wrote it  
- Search within the catalog  
- The original files left in place if you chose not to copy  
- A database you should back up if the tags matter  
- No stock download and no social network required

## Troubleshooting

- Thumbnails are broken? The files moved. Relink the folder. Do not re-download replacements.  
- A photo is not yours? Remove it from the catalog and from the disk if you should not have it.  
- The database is the only place your tags exist? Copy that database when you back up. The JPEGs alone may not have every tag you typed.
